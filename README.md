# EvidenceFlow
A visual automation builder where users connect steps such as reading a document, extracting information, translating text, and generating a report.

## Windows portable review downloads

The Windows review workflow exports a standalone x64 ZIP, verifies the engine/template SHA512 pins, builds the native save library, sets and reads back PE0.1.0.0, and smoke-tests persistence and the main scene from the extracted ZIP. Successful runs retain a unique private draft Release with server-verified SHA256. Repository writers can download the ZIP from Releases, extract the complete folder and launch EvidenceFlow.exe without Python or Godot installed. These are unsigned review builds, not production releases. No AI model/server is bundled; local AI requires a separately configured loopback server. Android APKs and full release acceptance remain open.
